# 📚 MantraPath Documentation

This directory contains all comprehensive documentation for the MantraPath project, organized by category for easy navigation.

### 🏗️ Architecture Documentation (`architecture/`)

- **Service analysis and documentation**
- **Voice models and event schemas**
- **Scalability and infrastructure planning**

### 🛡️ Security Documentation (`security/`)

- **Security enhancement reports**

### 📋 Implementation Reports (`implementation-reports/`)
- **Sprint completion reports**
- **Feature implementation summaries**
- **Test results and validation**

### 🎨 Assets (`assets/`)
- **Diagrams and visual documentation**
- **Screenshots and UI mockups**
- **Brand assets and logos**

### 🔬 Models (`Models/`)
- **Data models and schemas**
- **AI/ML model documentation**
- **Database design documents**

### 💡 Planning (`insight-planning-phase-2/`)
- **Future development planning**
- **Insight generation strategies**
- **Research and exploration documents**

## 📖 How to Navigate

1. **For Architecture Understanding**: Start with `architecture/`
2. **For Implementation Status**: Check `implementation-reports/`
3. **For Security Information**: Review `security/`
4. **For Visual References**: Browse `assets/`
