## 🎨 Brand Standards Reference

### Color Palette
- **MantraPath Blue**: #3B82F6 (Primary branding, CTAs)
- **Healing Green**: #10B981 (Success states, positive messaging)
- **Hope Amber**: #F59E0B (Warning states, attention)
- **Gentle Purple**: #8B5CF6 (Secondary actions, highlights)

### Typography
- **Primary Font**: Inter (400, 500, 600, 700 weights)
- **Headings**: Inter Bold (700)
- **Body Text**: Inter Regular (400)
- **UI Text**: Inter Medium (500)

### Logo Usage
- **Primary Logo**: Full color logo with tagline
- **Icon Version**: Symbol only for small spaces
- **Minimum Size**: 24px for digital, 0.5 inches for print
- **Clear Space**: 1x logo height on all sides
